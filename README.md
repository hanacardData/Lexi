# LEXI

인덱싱 없이 빠르게 로컬 파일을 찾는 Windows용 파일 검색 도구입니다.

## 기능

- 여러 폴더에서 파일명/파일 내용 검색
- 탭으로 여러 검색을 동시에 유지
- 파일 패턴 필터 지원 (`*.pdf`, `*.{pdf,csv}`, `!dir/` 등)
- 검색 결과 하이라이트, 수정 일시 기준 정렬
- 결과에서 파일 열기, 폴더 열기, 경로 복사
